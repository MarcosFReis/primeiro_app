#  Seriando App — Aplicativo Mobile (Projeto Acadêmico)

Este aplicativo foi desenvolvido como parte de um projeto acadêmico focado em criar uma experiência moderna e fluida para que os usuários possam pesquisar filmes e séries de seu interesse e conferir o máximo de informações possíveis. O projeto foi construído em um ambiente de equipe extremamente colaborativo e focado em resultados, contando com um grupo enxuto de 3 integrantes no total.

##  Meu Papel no Projeto
Dentro do time, assumi a parte técnica em duas frentes cruciais do sistema:
* **Parte Gráfica e Componentização (Front-end):** Desenvolvimento dos componentes visuais e telas do aplicativo, garantindo uma usabilidade limpa, moderna e responsiva.
* **Conexão com a API:** Implementação de toda a camada de consumo de dados, gerenciando requisições assíncronas e integrando os endpoints do back-end diretamente na interface gráfica.

##  Stack Tecnológica
* **TypeScript:** Linguagem principal do projeto, utilizada para garantir segurança, tipagem forte e manutenibilidade do código.
* **Ionic Framework:** Utilizado para o desenvolvimento da estrutura híbrida e componentização do aplicativo mobile.
* **Firebase:** Integração com serviços de infraestrutura em nuvem para gerenciamento do app.
* **Consumo de APIs:** Arquitetura de consumo e tratamento de payloads de serviços externos em tempo real.

##  Aprendizados 
Mais do que o desafio técnico de arquitetar interfaces com Ionic e TypeScript, o grande diferencial deste projeto foi a dinâmica de trabalho em equipe. Durante o projeto, tivemos que mudar de idéia algumas vezes devido a conectividade das Apis que estávamos testando. Sendo um grupo de apenas 3 pessoas, conseguimos dividir as tarefas com máxima eficiência, resolver gargalos de integração juntos e manter um fluxo de comunicação transparente e ágil do início ao fim.
